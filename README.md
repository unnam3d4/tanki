# Танки: Защити Базу!

HTML5 arcade-defense игра для Яндекс Игр.

## Статус
Production rebuild in progress.

## Цели
- быстрый старт и короткие игровые сессии;
- mobile-first управление;
- уровни, сложности и прогресс;
- улучшения между волнами;
- Yandex Games SDK;
- реклама, сохранения и лидерборды;
- GitHub Pages для постоянного тестирования.

## Структура
```
/
├── index.html
├── src/
├── assets/
└── README.md
```

GitHub Pages используется как тестовый стенд. Финальная сборка будет отдельно готовиться под загрузку в Яндекс Игры.
