# Танки: Защити Базу!

HTML5 arcade-defense игра для Яндекс Игр.

## Текущая production-версия

- коммерческий UI главного меню;
- выбор уровня и сложности;
- полноценный экран настроек;
- громкость и отключение SFX;
- тряска экрана выключена по умолчанию;
- автопауза при потере фокуса;
- 6 уровней, элитные враги и босс;
- улучшения между волнами без emoji-графики;
- desktop + mobile управление;
- сохранение прогресса и пользовательских настроек;
- отдельный адаптер Yandex Games SDK;
- GitHub Pages как live preview.
