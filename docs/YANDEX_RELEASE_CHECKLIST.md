# Yandex Games release checklist

## SDK и жизненный цикл

- SDK подключается до вызова YaGames.init().
- На GitHub Pages / custom domain используется абсолютный SDK URL.
- В Yandex-hosted build используется /sdk.js.
- LoadingAPI.ready() вызывается после готовности игры.
- GameplayAPI.start() вызывается при старте/возобновлении боя.
- GameplayAPI.stop() вызывается в меню, на паузе и при потере фокуса.

## Звук и фокус

- При потере фокуса бой автоматически ставится на паузу.
- AudioContext при скрытии страницы приостанавливается.
- У игрока есть настройка громкости и отключения SFX.
- Тряска экрана отключена по умолчанию и включается только вручную.

## Управление и UX

- Desktop: клавиатура + мышь.
- Mobile: полностью сенсорное управление.
- Long tap/context menu не должен мешать игре.
- Игровая область сохраняет безопасное соотношение сторон.
- Меню, пауза, настройки и возврат в игру доступны без внешней авторизации.

## Build

- index.html находится в корне.
- Пути и имена файлов — латиницей, без пробелов.
- Нет внешних обязательных ассетов для запуска.
- Перед релизом проверить итоговый размер архива.

## Перед модерацией

- Прогнать Yandex debug panel.
- Проверить desktop и mobile.
- Проверить скрытие/возврат вкладки.
- Проверить первый запуск и guest progress.
- Проверить поведение рекламы после её подключения.
- Проверить Player Data и leaderboard после их подключения.
