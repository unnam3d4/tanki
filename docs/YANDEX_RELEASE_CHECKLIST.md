# Yandex Games release checklist

## SDK

- SDK инициализируется до использования API.
- LoadingAPI.ready() вызывается, когда игра уже готова к старту.
- GameplayAPI.start() вызывается непосредственно при старте/возобновлении боя.
- GameplayAPI.stop() вызывается при паузе, меню, скрытии вкладки и показе рекламы.

## Build

- index.html лежит в корне архива.
- Имена файлов и папок — латиница, без пробелов.
- Нет debug/dev заглушек.
- Распакованный размер билда не превышает лимит платформы.

## QA

- Desktop: Chrome / Yandex Browser / Firefox / Safari.
- Mobile: Android + iOS touch input.
- Проверить изменение размера окна и ориентации.
- Проверить сворачивание/возврат в игру.
- Проверить возврат после fullscreen/rewarded рекламы.
- Проверить сохранение прогресса без авторизации и после авторизации.
- Проверить первый запуск, быстрый старт, паузу, рестарт и переход между уровнями.
