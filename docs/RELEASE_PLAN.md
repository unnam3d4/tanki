# План релиза — «Танки: Защити Базу!»

Цель: довести текущий GitHub Pages билд до законченной HTML5-игры для публикации в Яндекс Играх.

## 0. Уже готово

- [x] GitHub + GitHub Pages
- [x] Yandex Games SDK bridge
- [x] LoadingAPI.ready()
- [x] GameplayAPI.start()/stop()
- [x] game_api_pause / game_api_resume bridge
- [x] Desktop + touch controls
- [x] Автопауза и остановка звука при потере фокуса
- [x] Настройки громкости / SFX / shake / autopause
- [x] Тряска экрана выключена по умолчанию
- [x] Контекстное меню блокируется в игровом поле
- [x] Убраны постоянные тёмные точки и кратеры с фона
- [x] 30 уровней, волны, боссы каждые 5 уровней, апгрейды
- [x] Локальный прогресс

## A. UX-каркас

- [ ] Главное меню: Играть / Продолжить / Настройки / Рейтинг
- [x] Выбор уровня и последовательное открытие кампании
- [ ] Пауза

- [ ] восстановить базу

- [ ] reroll улучшений

- [ ] сохранить прогресс
